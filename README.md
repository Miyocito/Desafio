# Desafio
Prototipo de IA Multi-Agente para detectar y certificar fraudes financieros. Procesa texto de reclamos mediante 5 agentes secuenciales: extrae datos, halla patrones, mide el impacto en transacciones, genera reglas lógicas y hace backtesting de efectividad. Todo con datos sintéticos y una UI interactiva con trazabilidad.
